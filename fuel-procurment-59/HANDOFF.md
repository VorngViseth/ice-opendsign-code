# Ice factory prototype — coworker handoff

This is the current editable HTML/CSS/JavaScript prototype, exported on 30 September 2026. It is not the archived React version.

## Run locally

Unzip the archive, then open the ice-factory-prototype folder in your editor.
With Python 3 installed, run from that folder:

```sh
python3 -m http.server 5173 --bind 127.0.0.1
```

On Windows, use `py -3` instead of `python3` if needed.
Open http://localhost:5173/ for Walk-in Sales or http://localhost:5173/executive-overview.html for Reporting.
If Node.js/npm and Python 3 are both installed, `npm run dev` runs the same server. There are no npm dependencies to install for the current static prototype.

## Edit the design

- `Design.md`: shared design guidance.
- `index.html`, `app.js`, `styles.css`: walk-in sales.
- `driver-sales.*`: driver sales and dispatch receipt preparation.
- `debt-collection.*`: collection tickets and recording.
- `dispatch-*.html`, `dispatch.html`, `dispatch-workflow.*`, `dispatch-store.js`, `shared-dispatches.js`: dispatch screens and shared data.
- `daily-finance.*`: finance.
- `executive-overview.*`, `executive-data.js`: reporting navigation, overview and detailed reports.
- `production-sales.*`, `production-data.js`: production-versus-sales reporting.
- `*-DECISIONS.md`, `DECISIONS.md`: reviewed rules and outstanding decisions.
- `references/teammate-dispatch/`: original teammate references, not active application pages.

Edit source files and refresh the browser. Keep English/Khmer text, shared navigation and business rules consistent. Some UI is generated by JavaScript, so changing HTML alone may not update every label. Google-hosted fonts require internet access; browser fallbacks are used otherwise.

## Data and device features

Built-in sample data is included. Transactions and evidence saved in the original browser are not part of this archive. Local browser records do not sync between coworkers or with the hosted prototype. Camera capture needs permission and HTTPS or localhost. Physical printing and browser visual verification remain outstanding.

## Build and publish

With Node.js installed, run `npm run build` to create `dist/`. The build script has an explicit file list: add new runtime files there when adding screens or assets.
`vercel.json` deploys `dist/`, and `.vercelignore` limits uploaded files. Run the build before deploying. Use your own authorized hosting account and a separate preview project unless updating the shared production site is intended. Existing deployment notes are historical context, not a requirement to deploy to the original account.
